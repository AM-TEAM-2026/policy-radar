Vungle SDK for Android/Amazon v7.7.7 新增原生广告中 AI 生成内容的披露标签支持

Vungle SDK for Android/Amazon 发布 v7.7.7 版本（2026-07-24），新增对原生广告中 AI 生成内容的披露标签（disclosure labeling）支持，并包含稳定性改进。

业务影响

涉及广告合规与内容治理：在原生广告中展示 AI 生成内容需进行披露标注，可能影响广告素材审核、展示合规性及用户体验；未适配可能导致合规风险或广告被拒投。

需要行动

1) 评估当前原生广告中是否存在 AI 生成内容并梳理披露需求；2) 升级至 Vungle SDK v7.7.7 并接入披露标签能力；3) 更新广告素材审核与上线流程以纳入 AI 内容披露校验；4) 关注后续应用商店对 AI 生成内容披露的强制要求。

Unity
· Unity LevelPlay Documentation · 发布 2026-03-26官方确认
P2广告变现2026-04-30 已生效

ironSource Ads direct demand 业务停止

Unity 将于 2026-04-30 停止 ironSource Ads direct demand；ironSource Exchange/programmatic demand 和 LevelPlay 不停止。

业务影响

ironSource Ads direct demand 停止会直接切掉这部分填充与收入；ironSource Exchange 和 LevelPlay 不受影响，因此损失取决于 direct demand 在自家瀑布中的占比。

需要行动

统计 ironSource direct demand 当前的收入与填充占比；在 2026-04-30 前用其他需求源补足对应库存；停服后监控整体 eCPM 与填充率。

InMobi
· InMobi What's New · 发布 2026-02-27官方确认
P2广告变现2026-02-28 已生效

InMobi CMP / IAB Europe TCF v2.3 迁移

TCF v2.3 将 disclosedVendors 段改为必填；过渡期于 2026-02-28 结束，2026-03-01 起新生成且缺该段的 TC String 无效。

业务影响

TCF v2.3 把 disclosedVendors 改为必填，2026-03-01 起新生成且缺该段的 TC String 无效——欧盟区的同意信号会失效，直接导致个性化广告收入下滑。

需要行动

确认 CMP 已升级到输出 v2.3 且包含 disclosedVendors；在过渡期结束前用真实设备验证欧盟区 TC String 的有效性；上线后监控欧盟区 eCPM。

Pangle
· Pangle Resources · 发布 2026-02-12官方确认
P3广告变现2026-02-12 已生效

Pangle 在美国上线广告变现服务

Pangle 宣布美国市场广告变现服务上线，SDK 版本达到 7.2.0.2 及以上的应用可直接在美国变现，支持激励视频与插屏格式，并已接入 TopOn、TradPlus、LevelPlay 等中介。团队内部通知记录的时间是 2026-02-04，官方公开资源页标注 2026-02-12，此处按公开发布日期记录。

业务影响

美国是变现 eCPM 最高的市场之一，Pangle 开放美国供给意味着瀑布或竞价里多一个可用需求源；但接入前要确认 SDK 版本与中介配置，否则不会实际起量。

需要行动

确认当前 Pangle SDK 版本是否已达 7.2.0.2；在中介后台开启美国流量并小流量灰度；对比开启前后美国区的 eCPM 与填充率再决定放量。

Unity

P2广告变现2026-01-31 已生效

Unity Ads Waterfall 接入停止并迁移至 Bidding

自 2026-01-31 起，Unity Ads 对 Google AdMob/Google Ad Manager 只支持 bidding，剩余 waterfall instances 不再投放。

业务影响

Unity Ads 对 AdMob / Ad Manager 只保留 bidding，剩余 waterfall instance 直接停投；未迁移的部分会出现无声的填充缺口。

需要行动

在 Unity 后台确认 AdMob / Ad Manager 的接入方式是否已全部为 bidding；清理残留 waterfall instance；迁移后对比填充率与 eCPM。

AppLovin
· AppLovin Developer Documentation · 发布 2025-12-16官方确认
P2广告变现2025-12-16 已生效

AppLovin Publisher Policies 受限内容可个案许可

AppLovin Publisher Policies 将赌博、酒精、政治、烟草、金融、健康等列为 restricted content，平台可在符合地区规则等条件时酌情允许变现。

业务影响

赌博、酒精、政治、烟草、金融、健康被列为受限内容，但平台保留个案许可的空间；对相关品类的变现意味着需要逐案沟通而非一刀切禁止。

需要行动

确认自家内容是否落入受限清单；落入的向 AppLovin 申请个案许可并留存书面确认；未获许可前不要按可变现假设排收入。

Unity
· Unity LevelPlay Documentation · 发布 ≤2025-10-30
P2广告变现2025-10-30 已生效

Ad Quality SDK 接入方式变化

ironSource SDK 8.10.0 及以上、MAX SDK 13.0.0 及以上不再自动包含 Ad Quality，需要单独集成。该条来自团队内部整理记录，官方文档页未见同样表述。

业务影响

升级 SDK 后如未单独集成，Ad Quality 的数据会静默消失，广告质量与收入归因的可观测性下降，且不会有报错提示。

需要行动

核实官方文档中的集成要求；升级到相应版本时同步单独集成 Ad Quality，并在升级后确认数据仍在上报。

AdMob
· Google AdMob Help · 发布 2025-10-22官方确认
P2广告变现2025-10-22 已生效

AdMob iOS IDFV 向 RTB 需求方共享

在允许个性化广告时，AdMob Publisher 可将 iOS IDFV 发送给 Authorized Buyers、Open Bidders 和 SDK Bidders，部分地区除外。

业务影响

允许个性化广告时 IDFV 会被发送给 RTB 需求方，可能提高竞价填充与 eCPM；同时增加了向第三方传输设备标识的隐私披露义务，且 EEA、英国、瑞士与部分美国州不适用。

需要行动

确认自家隐私政策与 ATT 说明是否覆盖向需求方共享 IDFV；核对受限地区的行为是否已自动排除；观察启用后 eCPM 与填充率变化。
