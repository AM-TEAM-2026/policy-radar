PayPal 已解决原生移动应用商户 PayPal Checkout 受影响事件

PayPal Status 于 2026-08-04 14:32:37 GMT 发布已解决通告，事件编号 PP-LIVE-107938，涉及商户原生移动应用中的 PayPal Checkout 受影响问题，现已恢复。

业务影响

该事件曾影响商户原生移动应用内的 PayPal Checkout 支付流程，可能导致用户在应用内无法完成 PayPal 支付或结账失败；现已解决，支付链路恢复，对订阅与支付可用性影响为短期、已修复。

需要行动

核查监测窗口内原生移动应用端的 PayPal Checkout 交易成功率与错误日志，确认恢复情况；复盘受影响订单并视情况进行重试或用户沟通；更新内部事件记录与告警基线。

建议责任方 支付与商户平台运维/支付产品团队

Adapty

Adapty 支持 Apple Retention Messaging API 及新增 Flow & Paywall Builder 模板

Adapty 于 2026 年 8 月发布更新，新增对 Apple Retention Messaging API 的支持，允许开发者在取消订阅界面发送价值提醒、折扣或套餐切换信息，支持无 SDK 更新配置、设备端预览、AI 本地化及保存率分析。同时推出新的 Flow & Paywall Builder 模板（入职测验、折扣优惠、单屏付费墙），支持无需发版即可上线。此外，新增按需同步 Apple Ads 数据功能。

业务影响

提升订阅留存管理能力，优化付费墙和入职流程配置效率，增强 Apple Ads 数据同步灵活性。

需要行动

评估是否启用 Apple Retention Messaging API 以提升订阅留存；测试新模板并考虑替换现有付费墙或入职流程；配置按需同步 Apple Ads 数据以确保数据实时性。

Stripe TWINT 计划维护（7 月 29 日）

P3三方支付已正式发布

PayPal EMEA 提现服务降级已恢复

PayPal 官方状态页显示，生产环境的 Withdrawals 服务在 EMEA 地区出现性能降级；事件自 2026-07-27 10:44 UTC 持续至 2026-07-28 06:45 UTC，随后影响已缓解并关闭。PayPal 表示技术团队仍在确保完全恢复。

业务影响

受影响时段内，EMEA 地区的 PayPal 余额提现可能延迟或失败，进而影响商户或收款方的资金可用性与结算节奏；官方未说明在线收款或结账服务受到影响。

需要行动

核对受影响时段内的提现记录与到账状态，重试失败提现，并持续观察 PayPal 状态页是否出现复发或后续说明。
