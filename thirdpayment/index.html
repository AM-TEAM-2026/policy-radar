FunnelFox 分析指标与订阅计算逻辑更新

FunnelFox 更新了 Analytics 中的订阅和购买指标计算方式：购买现包含付费试用、转化和追加销售，排除续订和免费试用；新订阅仅计首次付款；活跃订阅在付费期结束前保留已取消状态；流失率计算不再区分自愿和非自愿。此外，Solidgate 订阅交换现保留试用期，订阅 API 新增 cancel_scheduled 字段以显示计划取消状态及失去访问权限的日期。

业务影响

需要行动

重新评估历史数据和新指标口径，调整内部数据分析逻辑和报表；更新订阅 API 集成代码以利用 cancel_scheduled 和 period_ends_at 字段；检查并确认 Solidgate 交换逻辑符合业务预期。
