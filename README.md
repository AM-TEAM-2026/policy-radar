# Policy Radar

出海 App 平台政策与业务风险雷达。按业务域（开发者平台、买量、广告变现、三方支付、AI、监管、其他）呈现政策事件，附时间线、事件生命周期永久链接和来源同步状态。

网站地址：<https://am-team-2026.github.io/policy-radar/>

## 关于本仓库

本仓库**只存放生成后的静态网站产物**，不含任何生成逻辑、抓取代码或运行状态。

- 页面由私有仓库的 Python + Jinja2 流程生成（`automation/build_radar_data.py` → `automation/build_radar_site.py`），每次重新生成后整体覆盖。
- **请不要直接手改本仓库的 HTML。** 改动会在下一次生成时被覆盖；需要修正内容或样式请回私有仓库改生成器。
- 所有展示内容均来自公开信息源（各平台官方政策页、监管机构公告、公开媒体报道）。不含 Token、密钥、内部检查点或运行日志。

## 内容边界

事件的业务优先级（P0-A ~ P4）反映的是对本团队的行动紧迫度，判定口径以应用商店政策要求为准；监管机构直接发布但尚未被商店政策吸收的内容默认为持续关注级别，不代表对相关监管要求的法律意见。
